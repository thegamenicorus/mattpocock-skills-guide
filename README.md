# Matt Pocock Skills: Daily Developer Guide

A single-page guide explaining how to put Matt Pocock's Claude Code skills to work in everyday development — covering use cases, the mental model behind the skills, caveats to watch for, and a "Start Here" path for new users.

## Live site

Published via GitHub Pages: https://thegamenicorus.github.io/mattpocock-skills-guide/

## Contents

- `index.html` — the entire guide (HTML + inline CSS, no build step)

## Local preview

Just open the file in a browser:

```sh
open index.html
```

Or serve it with any static server, e.g.:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploying

This repo is configured for GitHub Pages from the `main` branch root. Push to `main` and GitHub Pages will pick up the change automatically.
